# Web Refresher: Tech Stack Trivia

A single-page and responsive trivia quiz application built with semantic HTML5, CSS Grid/Flexbox and vanilla JavaScript.

## Reflection

The development of this single-page quiz has provided a clear opportunity to practice vanilla DOM manipulation and responsive layouts without relying on modern component frameworks. 

The structuring of the semantic layout using `<header>`, `<main>`, `<section>` and `<footer>` tags was direct and styling the primary card using CSS Flexbox was also smooth. The implementation of the multiple-choice option grid via CSS Grid and  smooth transitions to a single-column layout on mobile devices using media queries also completed seamlessly.

The main challenge was handling state transitions cleanly in JavaScript—specifically to prevent duplicate answers after a selection is clicked and resetting the DOM container efficiently between questions. 

Moving forward into Web Development II, the main skill I want to refine is state management across components especially as we transition from imperative DOM updates to declarative React interfaces.
